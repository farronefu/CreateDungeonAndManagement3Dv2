# Shared irregular block relief

The six original GLBs and color atlases are unchanged. A single indexed, 1440-triangle shell replaces their flat geometry. Every face has a 6x6 stepped surface with connecting walls and a small number of broad patches and corner recesses. Four fixed height profiles per face are selected from the existing deterministic cell seed. Rock uses one broad shallow pit and a corner recess. Other stages retain one broad raised patch and one connected corner hollow; mixed moss prefers raised patches near existing green pixels. The entire shell remains inside the 0.985 x 0.88 x 0.985 m bounds, with a 0.10 m shell inset; adjacent blocks retain their nominal 0.015 m gap.

No per-frame geometry allocation, TIME displacement or gameplay RNG was added. Nutrient changes select height/color channels while keeping the cell variant and quarter-turn rotation. The existing grid, picking, dig rules, persistence, crumble, debris and all actor/audio assets are unchanged. `VoxelBlockCatalog.surface_height` mirrors GPU displacement only for validation.

Authoring: `python tools/modelgen/block_surface_depth.py` regenerates the 24x36 RGBA height atlas (Pillow/numpy development dependencies). Keep this texture lossless, nearest-filtered, without mipmaps or sRGB conversion. RGBA channels are height data, not visual transparency. The reference image SHA256 is recorded in the accompanying JSON.

Regression: `scripts/debug/voxel_block_test.gd` requires a rendered Godot process; the dummy renderer does not retain MultiMesh custom data. The standard `tools/run_tests.sh` includes this check in addition to the 17 existing cases. It validates all nutrient boundaries, all six faces and four profiles, displaced bounds, connected peak patches, stable reload seeds, hover, bedrock, saves, dig/crumble and debris.

The original relief benchmark (before the seam and density adjustments) was measured from the old and new Windows PCKs in explicitly windowed mode, with both window size and rendered image size verified as 1280x720, seed 3, frozen scene, 60 warm-up and 120 sampled frames on RTX 3060 Ti / Godot 4.7.2 Forward+: median 16.667 -> 16.691 ms, p95 17.760 -> 17.270 ms. The 77 MultiMeshes and 7150 slots are unchanged. Submitted block triangles across all chunks increase from 4,776,200 to 10,296,000; visible primitives from 4,344,510 to 7,007,910 and scene draw calls stay at 204. The earlier command-line resolution request alone did not disable the project's maximized window mode, so the verified windowed measurements replace those figures. These timings are for this scene and hardware, not a claim about all GPUs or all viewpoints.

The seam adjustment widens only the visual X/Z envelope from 0.97 to 0.985 m on the unchanged 1 m grid. Height stays 0.88 m and the height atlas, relief depth, nutrient colors and game calculations are unchanged. Neighbor-envelope regression checks both grid axes and requires a positive 0.015 m gap.

The restrained profile update reduces mean internal height-change boundaries per face from 29.323 to 13.781 (53.0%). Each of the 96 face/variant/channel profiles has at least 20 of 36 cells in one connected flat region (mean 25.208, about 70%). Profiles use three height levels instead of many small per-cell changes. Face-internal height range is 0.035 m for rock and 0.040 m for the other stages, versus about 0.101 m previously; the shell inset changes from 0.12 to 0.10 m. The 0.985 x 0.88 x 0.985 m envelope and 0.015 m nominal seam remain fixed.

The shared indexed mesh remains at 1440 triangles, 77 MultiMeshes and 7150 slots. Equal-height walls collapse geometrically, so fewer visible steps do not imply a reduction in submitted vertex/triangle count. No per-frame geometry or gameplay RNG was introduced. The generator records density, connected plane areas and height ranges for every profile; rendered regression checks these budgets along with existing gameplay behavior.
