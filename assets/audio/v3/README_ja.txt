MonsterChain v3 統合音声ガイド（最終版）

収録：SE15音、採用済みBGM3曲、新規BGM2曲。

採用BGM：v2 02→build、03→battle、04→captured。元OGGデータを完全同一コピー。
追加BGM：title=タイトル待機、result_victory=勝利SE後の勝利リザルト／強化購入画面。
敗北はSEのあと無音。魔王配置・カットイン専用BGMは追加しない。

重要：現在のSfx.playは_streamsに無いキーを無視するため、新キー登録と発火箇所の変更が必要。
同名WAVがあるとOGGより優先される。採用BGMをOGGで使う時は、古い同名WAVが残って新音源を隠さないように実装側で扱う。
WAVを継続する場合は、v2 BGM2/3/4の元WAVをそのまま使用。

SEは32kHz/16-bit PCM/mono。採用7音の音声データは完全同一。spawn_bugのみ元04の先頭110ms、末尾6msフェード。
clickはUIの決定／確定に限定。eatの旧音はbee_attackへ転用し、捕食用途には使わない。
missは空振り・無効操作・対象なし・魔物へのツルハシ攻撃で同一音を共用。

hero_attack.wav / 勇者の攻撃・タンッ
勇者の攻撃が魔物に命中する瞬間。攻撃の開始音やブレーカー攻撃と区別し、1ヒットにつき1回。

pillbug_die.wav / ダンゴムシ死亡・パキッ
ダンゴムシ通常形態（BUG LARVA）と進化途中の丸まった形態（BUG PUPA）が死亡した瞬間。

pillbug_evolve.wav / ダンゴムシ→蜂・ブンッ
ダンゴムシが蜂（BUG ADULT）へ進化し、姿が切り替わる瞬間に1回。PUPAへ丸まる段階には鳴らさない。

spawn_moss.wav / 草／コケ誕生・ポトッ
採掘や繁殖によって草／コケ系が新しく生まれた瞬間。セーブ読込による復元では鳴らさない。

miss.wav / 空振り・スカッッ
掘れない場所／対象なしへ操作した時と、ツルハシ／ブレーカーで魔物を攻撃した時。これらすべてに同じmiss音を使う。

grass_evolve.wav / 草系進化・ふわっ、ぽわん
草／コケ系（MOSS）がBUDまたはFLOWERへ進化し、形態が切り替わった瞬間に1回。虫の進化や強化購入とは別。

upgrade.wav / リザルト強化購入・テレテレ
リザルトの強化購入が成功して能力が上がった時だけ。購入失敗、画面表示、通常のUI決定では鳴らさない。

spawn_bug.wav / ダンゴムシ誕生・ポポッ（冒頭のみ）
採掘または繁殖でダンゴムシ系が新しく生まれた瞬間。v2 SE04の冒頭2打だけを再生。

dig.wav / 掘削成功・土と石の崩れ
掘れる土／岩ブロックを1マス壊した直後。空振り時や魔物へのツルハシ攻撃ではmissを使う。

bee_attack.wav / 蜂の攻撃（v2 SE09を転用）
ダンゴムシから進化した蜂の攻撃が対象へ命中する瞬間。捕食イベントには使わない。

grab.wav / 魔王捕獲
勇者が魔王を捕まえ、連れ出しを開始した瞬間。

door.wav / 地上の門が開く
勇者が侵入する地上の門を開く瞬間。

click.wav / UI決定のみ
ボタンの決定／確定操作の成立時だけ。カーソル移動・ホバー・キャンセルには使わない。

victory.wav / 勇者撃退・勝利
勇者を倒して勝利結果へ移る瞬間に1回。

defeat.wav / 魔王搬出・敗北
勇者が魔王を連れたまま入口から脱出し、敗北となった瞬間に1回。

title.ogg / 地底の看板 / 41.74秒
タイトル画面の待機中。建設曲とは分け、低い主題と余白でゲームの入口を作る。

result_victory.ogg / 地下のひとやすみ / 48.00秒
勝利SEの後、勝利リザルト画面で成績確認・強化購入中に流す。敗北画面では使わない。

検証：採用データのSHA-256一致、全SEのクリップ・ピーク・RMS・終端、新BGMの全体ループ・OGG復号サンプル数を確認。音源の耳による主観試聴は行えていない。
ゲーム内での発音条件、重なり、音量は実装担当のテストが必要。
この音源制作ではリポジトリを変更していない。

作成ソースはsourceに収録。全再生成にはv2音源フォルダーも必要。generate_v3.py→compose_additional_bgm.py→finalize_v3.pyの順。
